      已新增的 Passkey

        應用程式帳密

        給捷徑、腳本等程式呼叫書籤 API，以 Basic Auth 帶在 Authorization header

        帳號與密碼由系統產生。密碼只在建立後顯示這一次，伺服器只保存雜湊，之後無法再查看；遺失時刪除重建即可。只能呼叫 /api/bookmarks 與 /api/preview，不能變更設定。每次呼叫都會留下紀錄，超過保留天數或筆數的自動刪除。

        確認身分後建立

        帳密等於多一種登入方式，請輸入目前密碼；已新增 Passkey 的話，也可以改用 Face ID、Touch ID 或 Windows Hello 驗證。

          通知信

          新增書籤時，寄網站資料與摘要給指定的收件人

          收件地址清空即停止寄送。儲存後按「寄測試信」，以最新一筆書籤確認每個地址都收得到。

          收件地址要先在 Cloudflare 驗證
          1. 寄件地址的網域需託管在 Cloudflare，並在 Dashboard → 該網域 → Email → Email Routing 啟用。
          2. 寄件地址填這個網域下的任一地址，例如 bookmark@你的網域，不必真的有信箱。
          3. 每個收件地址都要在 Email Routing → Destination addresses 新增，並請對方點開 Cloudflare 寄出的驗證信。
          4. 回到這裡按「寄測試信」。未驗證的地址會顯示錯誤，其他地址照常寄送。

          只寄得到已驗證的地址，所以不會誤寄給陌生人；新增收件人時記得先完成第 3 步。
