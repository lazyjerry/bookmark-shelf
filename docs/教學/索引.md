# 教學文件索引

這個資料夾收的是**教學**：解釋本專案用到的技術怎麼運作、在 Cloudflare 上怎麼做，給人從頭讀懂一套做法。

## 使用規範

- **收什麼**：技術概念、架構說明、在 Cloudflare 上的實作方式與範例程式碼。內容要能脫離當下任務單獨閱讀。
- **不收什麼**：API 規格寫在 `API.md`；動工計畫與施工結論寫在 `docs/working-notes-skill/`；使用者操作說明寫在 `README.md`、`SHORTCUTS.md`。
- **一個技術範圍一份小檔**：內容跨到另一個範圍時，另開一份並互相連結，不把多個主題塞進同一份。
- **檔名用中文**：`NN-主題.md`，`NN` 是兩位數的閱讀順序，同一系列連號；不同系列可以另起一段號碼（例如 10–19）。
- **標示狀態**：每份開頭寫明「已實作」或「設計說明，尚未實作」，實作後回頭更新，讓讀者知道範例跟現有程式碼對不對得上。
- **匿名化**：網域、帳號、金鑰一律用 `<網域>`、`<帳號>`、`API_KEY` 這類佔位，不寫實際值。
- **新增或改名後更新本索引**。
